# CHANGELOG
All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-16
- Initial release. Exposes Apple's StoreKit 2 framework to Unity developers with a C# async/await
  API on iOS, macOS, tvOS, and visionOS, covering:
  - Products and purchases, including promotional offers, purchase options, and advanced commerce
    products.
  - Subscriptions, subscription status and renewal info, and payment method binding.
  - Transactions, transaction verification, and refund requests.
  - App transactions, App Store messages, promoted product purchase intents, and `SKOverlay`.
  - Storefront lookup, plus events for observing storefront and subscription status changes.
